# Title-width companion dataset

**Same Character Count, Different Text Widths: 852 GOV.UK Guide Titles** — MTW-v1-2026.

[Original study, results and limitations](https://moltoyo.com/research/title-width-study) · [Versioned files](MTW-v1-2026/) · [Kaggle mirror](https://www.kaggle.com/datasets/stefanoperrelli/title-widths-852-english-gov-uk-guide-titles)

This companion is separate from the repository's primary English text-density dataset. It contains 852 title records and 74 exact-codepoint summary groups. The eight approved public files are copied without changing their bytes. Measurements were completed on 20 October 2026; the public projection and explanatory metadata were prepared on 30 October 2026. A mirror publication is not a new measurement date or dataset version.

The public Kaggle version-1 download was checked on 7 November 2026: all eight files match this version folder byte for byte. The licence selector there is “Other (specified in description)” to preserve the distinct CC BY 4.0 and OGL v3.0 scopes. See [verification evidence](kaggle-verification-2026-11-07.json).

Use the version folder's README for field definitions, attribution and reproduction of the statistics. Run the root `verify_research.py` to verify both releases. Historical hinting is unknown, widths are retained as whole pixels, and no Google rendering or search-performance claim is made.
